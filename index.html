Automated package repository for sing-box, sing-box-extended, and luci-app-singbox-ui.

Quick Setup on Router

Add custom feed to your router and install packages:

# Add repository feed (ARM64 Cortex-A53)
echo "src/gz mrvoki_repo https://mrvokintos.github.io/openwrt-repo/packages/aarch64_cortex-a53" >> /etc/opkg/customfeeds.conf

# Update package lists
opkg update

# Install singbox web interface and core (choose official or extended)
opkg install luci-app-singbox-ui sing-box
# OR for extended core:
# opkg install luci-app-singbox-ui sing-box-extended

Add repository file and install packages:

# Add repository feed (ARM64 Cortex-A53)
echo "https://mrvokintos.github.io/openwrt-repo/packages/aarch64_cortex-a53" >> /etc/apk/repositories.d/mrvoki.list

# Update package index
apk update

# Install singbox web interface and core
apk add --allow-untrusted luci-app-singbox-ui sing-box
# OR for extended core:
# apk add --allow-untrusted luci-app-singbox-ui sing-box-extended
